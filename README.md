# Python Study Tracker
A modern desktop application built with Python and CustomTkinter to help learners organize their Python studies, track exercises, manage projects, and monitor their learning progress.


## Features
- **Study Topics:** Track progress across 14 fundamental Python topics.
- **Exercise Counter:** Record the number of solved exercises for each topic.
- **Topic Completion:** Mark topics as completed.
- **Project Management:** Add, complete, and delete exercises and projects.
- **Progress Dashboard:** View completed topics, solved exercises, completed projects, and overall learning progress.
- **Dark Theme:** A modern dark interface with custom colors and styling.


## Built With
- Python
- CustomTkinter


## Purpose
This project was created to practice Python desktop application development, GUI design, and basic task and progress management.
